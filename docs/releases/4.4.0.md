# WordPress Starter 4.4.0

Released November 18, 2026.

## Source-only release

The release archives contain the starter source and dependency lockfiles. The generated Vite client assets, SSR bundles, and PrimeUI license key stay with each
site deployment. PrimeVue 5 and PrimeUIX Themes 3 are installed from npm. Set `VITE_PRIMEUI_LICENSE` in a local `.env` or in the site's build environment to use
your own PrimeUI license.

## What's new

- Updated the WordPress and frontend dependencies, including Inertia 3, VueUse 15, Vite 8, and Gravity Forms 3.2.3.1.
- Added installation guidance for Apache and Nginx on a regular server. Dokploy builds client and SSR assets when creating the site image.
- Improved SSR page metadata and Yoast integration, with smoke tests for public routes and private paths.
- Added responsive WordPress images with mobile art direction, Retina variants, and native image loading. Videos and background images use deferred loading.
- Added Vue animation directives for masked reveals, text reveals, and scroll zoom. GSAP loads when a directive needs it.
- Preserved existing Theme Settings identifiers while adding WPML language navigation and locale-aware Gravity Forms requests.
- Added project skills, CodeGraph configuration, and browser tests for forms, media, animation, navigation, and SSR.

## Upgrade

1. Use Node.js 26.13.1 or newer within the 26.x branch and PHP 8.4.1 or newer. Keep your existing WordPress database settings, salts, and uploads.
2. Install locked dependencies with `composer install` and `npm ci`.
3. Configure the site's PrimeUI key and run `npm run build`. Deploy the generated client and SSR directories with the corresponding PHP source.
4. Restart SSR if enabled and run the smoke checks for your deployment.

See the [ordinary server instructions](../server.md) and [Dokploy instructions](../dokploy.md) for the exact deployment paths.
